# Навчальний проєкт «Розумна машинка, яка виявляє перешкоди та планує маршрут за допомогою алгоритму A*» на ESP32

![Real Photo](/images/Searcher_photo2.jpg)

## Короткий опис
Це навчальний проєкт, який реалізує автоматичне керування моделлю автомобіля на мікроконтролері ESP32 з використанням IR датчика відстані Sharp (20–150 см) з сервоприводом MG90S для виявлення перешкод, двох оптичних енкодерів та дисків з прорізами для одометрії, акселерометра/гіроскопа MPU-6050 для визначення курсу, OLED-дисплея, зумера, двигунів та інших периферійних пристроїв. Розрахунок маршруту виконується алгоритмом A*; виявлені під час руху перешкоди додаються до карти перешкод, і маршрут перераховується відповідно.

## Основні можливості
- **Початок/Ціль:** Задайте координати старту та цілі для початку руху.
- **Планування A-star:** Обчислюється найкоротший маршрут (мінімальна відстань і кількість поворотів) з урахуванням відомих перешкод на момент розрахунку.
- **Дворівневий рух:** Кожен крок складається з повороту (кратного 45°) та прямолінійного руху.
- **Виявлення перешкод під час руху:** IR-датчик сканує в межах ±6° під час прямолінійного руху; при виявленні невідомої перешкоди рух зупиняється для широкого сканування.
- **Широке сканування:** Стаціонарне сканування ±90° для точного картографування нових перешкод (крок карти = 10 см).
- **Динамічне перепланування:** Нові перешкоди додаються на карту перешкод і A* перераховує маршрут; рух відновлюється при наявності маршруту.
- **Завершення руху:** Рух завершується по досягненню цілі або якщо неможливо побудувати маршрут.

## Керування моделлю
Для здійснення керування моделлю, мікроконтролер під’єднується до WiFi мережі та за допомогою веб-сервера надається відповідний інтерфейс, який дозволяє: задати координати цільової точки, почати рух, подивитись карту перешкод та маршрут руху, отримати інформацію з діагностики руху та використання ресурсів.

## Елементи та електрична схема
У проєкті використано наступні елементи:
- **Мікроконтролер:** ESP32 LuaNode32 Type-C (38-pin)
- **Двигуни:** Чотири редукторні DC двигуни (1:48, 6–8V) з колесами
- **IR датчик:** Sharp GP2Y0A02YK0F (20–150 см)
- **Сервопривід:** MG90S (для наведення IR датчика)
- **Енкодери:** Два оптичні енкодери + диски з прорізами (одометрія)
- **IMU:** MPU-6050 (акселерометр + гіроскоп)
- **Дисплей:** OLED 0.96" I2C 128×64
- **Зумер:** пасивний зумер
- **Живлення:** два акумулятори 18650, BMS 2S з балансуванням, понижуючий конвертер LM2596, модуль зарядки 2S (Type-C)

Електрична схема та з'єднання: ![Schematic](/images/Schematic_ESP32_SearcherAStar.png)

## Код програми
Проєкт створено в PlatformIO (Visual Studio Code + PlatformIO) з Arduino framework. Мова програмування C/C++. Використовується FreeRTOS для розподілу задач між ядрами ESP32 (WiFi/веб-сервер на одному ядрі, інші задачі на іншому). Алгоритм A* реалізовано за статтею «Pathfinding Demystified. Generic Search Algorithm. Practical A*» (https://www.gabrielgambetta.com/generic-search.html).

- **Джерела:** Код знаходиться в папці `src`.

### Збірка та прошивка (PlatformIO)
Відкрийте проєкт у VS Code з PlatformIO та виконайте збірку/прошивку через інтерфейс PlatformIO, або скористайтесь CLI:

```bash
platformio run -t upload
```
